# Roomba Controller

A console-based Roomba controller simulator written in Python. You control a Roomba in a 300 x 300 room through a text menu.

## Features
- Set a starting position and direction
- Move the Roomba forward, backward, left, or right
- Turn the Roomba left or right
- Let it roam randomly until it needs to recharge
- Run a recursive sweep pattern
- Random obstacle handling, where the Roomba adjusts its path
- Tracks elapsed time and distance traveled

## How to run
- Requires Python 3.
- Run this command:

```
python roomba.py
```

- Then follow the menu prompts.

## What I learned
- Breaking a program into small, reusable functions
- Using recursion for the sweep pattern
- Validating user input
